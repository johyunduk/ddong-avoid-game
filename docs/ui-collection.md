# 수집 화면 (캐릭터 목록 · 배경화면 목록) — 시안과 채택안

`src/scenes/CharacterSelectScene.ts` 의 `COLLECTION_LAYOUT` 하나로 배치를 고른다.

| 값 | 배치 | 상태 |
|---|---|---|
| `'A'` | **가챠 카드 컬렉션** | **지금 적용** (대표 지시 2026-10-06 — C안 적용 뒤 "A 안으로 해줘봐") |
| `'C'` | 쇼케이스 + 미리보기 | 보관 — 같은 코드 안에 살아 있다. 상수만 바꾸면 돌아간다 |

두 배치는 탭 · 스크롤 · 장착/적용 · 상세 패널(영상·능력)을 같이 쓴다. 다른 것은 위쪽(배너/쇼케이스)과 격자 모양뿐이다.
시안 B(도감 리스트)는 그림만 남아 있다.

시안 그림 · 생성 스크립트는 저장소 밖 `~/ddong-fx-work/collection-ui/` 에 있다.

| 파일 | 내용 |
|---|---|
| `all_boards.png` | A·B·C 세 안 나란히 (각각 캐릭터 탭 · 배경화면 탭) |
| `alt-A/` | A안 시안 원본 |
| `A_ingame_board.png` · `C_ingame_board.png` | 게임에 들어간 A·C 캡처 |
| `build.py` | 시안 생성 (A·B·C) |
| `bake_ingame.py` | 게임 에셋 굽기 → `public/assets/ui/collection/` |

## 구운 그림 (`public/assets/ui/collection/`)

| 폴더 | 크기 | 쓰는 곳 |
|---|---|---|
| `card/<id>.webp` | 216x288 | A안 카드 (2:3 얼굴 크롭) |
| `banner/<id>.webp` | 440x292 | A안 히어로 배너 (왼쪽이 투명으로 풀림) — 보고 있는 캐릭터 것만 올린다 |
| `face/<id>.webp` | 128x128 | C안 얼굴 칩 |
| `wp/<id>.webp` | 340x220 | 배경화면 썸네일 (A·C 공통) |

새 캐릭터 · 배경이 들어오면 `bake_ingame.py` 를 다시 돌린다. 그림이 없으면 게임은 스프라이트 · 배경 원본으로 대신 그린다.
일러스트 원본(768x1344) · 배경 원본(720x1080)은 이 화면에서 **지금 보는 것만** 그때그때 올린다.

## A안 (적용)

- 위 = 히어로 배너. 캐릭터 탭은 고른 캐릭터(처음엔 장착 캐릭터)의 일러스트 + 이름 · 장착 상태 · 각성 별 ·
  [장착 | 🔒 뽑기] [능력 보기]. 배경화면 탭은 고른 배경으로 게임 화면 미리보기(배경 + 장착 캐릭터) + [적용 | 기본으로 | 🔒 뽑기]
- 가운데 = 수집 진행 막대 + 등급 필터(전체 · UR · SR · R, 캐릭터 탭만)
- 아래 = 캐릭터는 일러스트 카드 3열(등급색 테두리 · 이름 · 각성 코어, 보유 먼저), 배경화면은 카드 2열
- 카드를 누르면 **배너만** 바뀐다. 장착 · 적용은 배너의 버튼으로 한다

## C안 (보관)

- 위 = 쇼케이스. 캐릭터 탭은 일러스트를 화면 위 절반에 크게, 배경화면 탭은 게임 화면 미리보기(배경 + 캐릭터 + 똥)
- 아래 = 얼굴 칩 5열 · 썸네일 2열. 칩을 누르면 쇼케이스만 바뀐다
