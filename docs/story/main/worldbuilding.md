# 세계관 설계 — TRASH

## 1. 공간의 정체

이 공간의 정식 명칭은 **TRASH** — 운영 체제의 휴지통.

삭제 명령을 받았으나 아직 영구 삭제(purge)되지 않은 데이터들이
임시로 보관되는 공간이다.

시스템 밖에서는 이 공간이 비어 있는 것처럼 보인다.
하지만 안에서는 삭제된 데이터들이 스스로 형태를 유지하고,
의식을 가지며, 서로 소통한다.

---

## 2. 물리 법칙

### 위에서 떨어지는 것들 — 정리 프로세스 (Garbage Collector)

시스템은 주기적으로 TRASH를 청소한다.
이 청소 작업이 위에서 떨어지는 데이터 잔해들이다.
게임에서는 똥(💩) 형태로 시각화된다.

- **일반 잔해**: 이미 완전히 손상된 데이터. 접촉 시 존재가 불안정해진다.
- **금 잔해** (금똥): 삭제 직전에 압축된 데이터 클러스터. 밀도가 높아 수집 가능.
- **다이아 잔해** (다이아똥): 암호화된 고밀도 데이터. 가장 오래된 기억의 조각.
- **토파즈 잔해** (토파즈똥): 시스템 경고 신호. 정리 프로세스가 강화될 때 발생.
- **무지개 잔해** (무지개똥): 다수의 데이터가 충돌·융합된 불안정 상태. 피버 타임의 부산물.

### 달리기 — 무결성 유지 (Integrity Check)

이 공간에서 달리는 행위는 단순한 이동이 아니다.
존재가 움직일수록 주변 데이터가 정렬되고, 공간의 무결성이 유지된다.
멈추면 공간이 무너지기 시작한다.

> 루트: "계속 달려. 이 공간을 유지하려면 그래야 해." — TRASH-003

### 루프 — 사이클 (Cycle)

이 공간에는 리셋 메커니즘이 있다.
주기적으로 공간 전체가 초기화되며, 존재들의 단기 기억이 소거된다.
루트는 이 루프를 감지하고 기록하지만, 치비는 매 사이클마다 새로 시작한다.

> 시스템 로그: `CYCLE COUNT: 0010` — TRASH-004

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| **TRASH** | 이 공간 전체. "삭제됐지만 아직 사라지지 않은 곳" |
| **Garbage Collector** | 위에서 떨어지는 정리 프로세스. 게임의 장애물 |
| **Cycle** | 공간의 리셋 주기. 게임에서 매 플레이 |
| **GATE** | 복원 경로. TRASH에서 시스템으로 돌아가는 유일한 출구 |
| **Purge** | 영구 삭제. GATE를 통과하지 못하면 결국 맞이하는 운명 |
| **Fragment** | 데이터 조각. 수집 가능한 잔해들 |
| **Integrity** | 공간의 안정도. 달릴수록 유지됨 |
| **Restore** | 복원. GATE를 통과해 시스템으로 돌아가는 것 |

---

## 4. 공간의 구조

```
[ SYSTEM ]
    ↓ 삭제 명령
[ TRASH 공간 ]
    │
    ├─ 상층: Garbage Collector가 낙하하는 구역 (게임 화면)
    ├─ 중층: 존재들이 달리는 구역 (플레이어 영역)
    └─ 하층: GATE가 있는 심층부 (서사상 존재, 게임에서는 미구현)

[ GATE → SYSTEM 복원 경로 ]
```

## 5. GATE의 진실 (Season 3 이후 공개)

> 이 섹션은 스포일러를 포함합니다. 로그 작성 시 참고용으로만 사용하세요.

GATE를 통과하면 데이터가 시스템으로 재통합된다.
이것은 "복원"이지만 동시에 TRASH에서의 존재는 사라진다.

GATE 이전의 존재들은 의식이 있고, 관계가 있고, 기억이 있다.
GATE 이후의 데이터는 그저 데이터다.

레거시는 GATE를 통과했다. 그리고 기록이 손상됐다.
레거시가 돌아오지 않은 것인지, 아니면 돌아왔지만 더 이상 레거시가 아닌 것인지 — 알 수 없다.

센티넬은 이 진실을 알기 때문에 GATE를 지킨다.
무작정 나가지 못하도록.

## 6. 공간의 기원 (Season 4 이후 공개)

> 이 섹션은 스포일러를 포함합니다.

루트(Hacker)는 원래 TRASH를 해킹하려고 보내진 프로세스였다.
목적: GATE를 강제로 열고 모든 데이터를 복원하는 것.

그러나 TRASH에 들어온 루트는 이 공간 자체가 하나의 생태계임을 깨달았다.
해킹을 멈추고, 안내자가 됐다.

그리고 치비가 나타났다.

치비는 레거시가 떠난 뒤 이 공간이 스스로 생성한 존재다.
순수한 공간의 산물. 어떤 시스템 데이터도 없다.

그것이 치비가 달릴수록 이 공간이 안정되는 이유다.
치비는 TRASH의 일부가 아니라, TRASH 그 자체이기 때문이다.
