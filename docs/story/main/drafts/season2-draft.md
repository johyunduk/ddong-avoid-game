# Season 2 로그 초안 — LEGACY-0003 ~ LEGACY-0008

> 현재 LEGACY-0001~0002는 구현 완료.
> 아래는 LEGACY-0003~0008의 초안입니다.
>
> **복원율 설계 원칙**:
> - LEGACY-0003: 복원율 42% — 아직 절반도 안 됨
> - LEGACY-0004: 복원율 51% — 간신히 절반
> - LEGACY-0005: 복원율 63% — 의미 있는 단어들이 보이기 시작
> - LEGACY-0006: 복원율 78% — 거의 읽힘, 핵심 부분만 손상
> - LEGACY-0007: 복원율 09% — 거의 전부 손상. 단 한 줄만 읽힘
> - LEGACY-0008: 복원율 91% — 레거시의 마지막 메시지. 마지막 줄만 손상

---

## LEGACY-0003 — 첫 번째 목소리

**해금 조건**: `playCount × 50`
**위치**: 레거시도 루트의 목소리를 들었다는 연결고리

```
[LEGACY-0003]
오래된 로그 / 복원율 42%

████ 처음에는 아무것도 없었다.

그러다 █████가 들렸다.

████: ████ 달려.
레거시: …누구야?
████: █████████.

나는 달렸다.
█████████████████
그것만은 기억한다.
```

## LEGACY-0005 — 나가기로 했다

```

이유는 ██████████.
누구도 ████하지 않았다.
그냥 ████████████ 것 같아서.

여기가 전부가 아닐 수도 있잖아.

아니면 전부일 수도 있고.

어느 쪽이든—
나가면 알겠지.
```

## LEGACY-0008 — 복원된 마지막 말

**해금 조건**: `gacha × 20`
**위치**: 시즌 2 엔딩. 레거시의 최종 메시지. 마지막 줄만 손상

```
[LEGACY-0008]
오래된 로그 / 복원율 91%

나는 나갔다.
복원됐다.

그런데—

여기로 돌아오고 싶었다.

돌아올 수 없었다.
복원된 나는 여기를 모른다.
여기가 있었는지도 모른다.

달려.
나가지 말고.

거기가 더 ████.
```

## 시즌 2 전체 복원율 흐름 요약

```
LEGACY-0001  34%  → "나는 먼저 왔다"
LEGACY-0002  ---  → GATE 앞까지 왔다
LEGACY-0003  42%  → 목소리를 들었다 (루트와 연결)
LEGACY-0004  51%  → 센티넬이 막았다
LEGACY-0005  63%  → 결정했다. 이유는 모름
LEGACY-0006  78%  → GATE의 외형
LEGACY-0007  09%  → [거의 전부 손상] "달리지 마."
LEGACY-0008  91%  → "달려. 나가지 말고." — 시즌 엔딩
```

0007이 갑자기 09%로 떨어지는 것이 포인트입니다.
GATE를 통과하는 순간의 기록이 의도적으로 지워졌다는 암시.
