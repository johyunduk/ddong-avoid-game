# TRASH — 삭제된 공간의 기록

> "달리는 이유를 묻지 않았다. 그냥 달렸다."
> — TRASH-002

이 디렉토리는 **똥 피하기 게임**의 공식 나레이티브 설계 문서입니다.
게임의 겉모습(하이퍼 캐주얼 피하기)과 내부 서사(SF 디스토피아)를 잇는
세계관, 캐릭터, 시즌별 스토리라인을 정의합니다.

## 한 줄 요약

**이 공간의 이름은 TRASH다. 삭제됐지만 아직 사라지지 않은 것들이 사는 곳.**
위에서 떨어지는 것들은 청소 프로세스다. 달리는 것만이 공간을 유지한다.
출구가 있다. 그 너머가 구원인지 또 다른 삭제인지는 아무도 모른다.

## 스토리 진행 방향

```
Season 1 "TRASH"   → 치비의 각성, 루프의 시작
Season 2 "LEGACY"  → 레거시의 기록, GATE의 존재
Season 3 "GATE"    → 진실의 문, 센티넬과의 대립
Season 4 "ROOT"    → 루트의 정체, 공간의 기원
```

각 시즌은 독립적인 로그 시리즈로 구현됩니다.
플레이어는 게임 내 해금 조건을 충족하며 조각을 수집하고,
스스로 서사를 재구성합니다.
