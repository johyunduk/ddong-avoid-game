## 🔖 버전 관리 규칙

이 프로젝트는 [Semantic Versioning](https://semver.org/lang/ko/)을 따릅니다:

- **Major (1.x.x)**: 대규모 기능 추가 또는 호환성이 깨지는 변경
- **Minor (x.1.x)**: 새로운 기능 추가 (하위 호환성 유지)
- **Patch (x.x.1)**: 버그 수정 및 마이너 개선
