## 신규 기능

### EXTREME 캐릭터별 랭킹

EXTREME 난이도에 캐릭터 필터가 추가됐습니다. 같은 캐릭터를 쓰는 플레이어끼리만 비교하는 독립 리더보드입니다.

- 랭킹 화면 상단 드롭다운에서 캐릭터를 선택하면 해당 캐릭터 전용 순위 조회
- 기존 전체 랭킹과 캐릭터별 랭킹을 자유롭게 전환 가능
- 캐릭터별 개인 최고 기록은 별도로 추적

### 캐릭터별 시즌 보상

매달 캐릭터별 랭킹 1~3위에게 SKOR 보상이 지급됩니다.

| 순위 | 보상 |
|------|------|
| 1위  | 5,000 SKOR |
| 2위  | 3,000 SKOR |
| 3위  | 1,500 SKOR |

- 보상 수령은 다음 달 랭킹 화면에서 직접 진행
- 여러 캐릭터로 각각 보상 수령 가능 (캐릭터별 독립)
- 기존 EXTREME 난이도 전체 랭킹 보상과 별개로 지급
