# v1.0.0 - 첫 번째 출시 🎉

**출시일**: 2025년 12월 13일

똥 피하기 게임의 첫 번째 공식 출시를 알립니다! 🎮💩

---

## 🎯 게임 개요

떨어지는 똥을 피하며 최대한 오래 살아남는 하이퍼 캐주얼 게임입니다.
간단한 조작, 중독성 있는 게임플레이, 그리고 친구들과 경쟁할 수 있는 랭킹 시스템까지!

---

## ✨ 주요 기능

### 🎮 게임 모드
- **클래식 모드**: 떨어지는 똥을 피하는 기본 모드
  - 3가지 난이도 (쉬움/보통/어려움) 선택 가능
  - 시간이 지날수록 점점 어려워지는 동적 난이도
  - 난이도별 다른 배경과 플레이어 속도

- **아이템 모드**: 우주 배경에서 별을 피하며 특수 아이템을 수집
  - 헤르메스 신발: 10초간 속도 2배 증가 ⚡
  - 무지개 별: 5초간 무적 상태 ⭐
  - 우주비행사 캐릭터로 플레이

### 💎 보너스 아이템 시스템 (클래식 모드)
- **금똥 (🏆)**: 40점마다 등장, 획득 시 +20점
- **다이아똥 (💎)**: 100점마다 등장, 획득 시 +40점
- 똑똑한 점수 시스템: 보너스 아이템을 먹어도 생성 타이밍을 절대 놓치지 않음!

### 🎄 크리스마스 이벤트
- 12월~1월 기간 동안 자동 활성화
- 크리스마스 테마 똥 5종 (산타, 루돌프, 선물 등)
- 특별한 크리스마스 배경과 음악
- 징글벨 BGM 리믹스

### 🏆 랭킹 시스템
- 난이도별 독립적인 리더보드
- 이니셜 입력으로 기록 등록 (3글자)
- 실시간 랭킹 조회 (상위 10명)
- 새 기록 달성 시 하이라이트 표시
- Firebase 실시간 데이터베이스 연동

### 🎵 사운드 & 비주얼
- 모드별 전용 배경음악
- 난이도별 차별화된 배경 이미지 (3종)
- 다양한 똥 캐릭터 (선글라스, 안경 등 5종)
- 우주 배경 및 별 장애물 (아이템 모드)
- 부드러운 애니메이션과 이펙트

### 🎮 편리한 조작
- 키보드: 좌/우 화살표 키
- 터치/마우스: 화면 좌우 탭
- 직관적이고 반응성 좋은 컨트롤

## 📊 게임 밸런스

### 난이도별 설정

| 난이도 | 플레이어 속도 | 기본 낙하 속도 | 생성 주기 |
|--------|--------------|---------------|----------|
| 쉬움   | 350 px/s     | 180 px/s      | 1200ms   |
| 보통   | 300 px/s     | 200 px/s      | 1000ms   |
| 어려움 | 250 px/s     | 220 px/s      | 800ms    |

### 동적 난이도 조정
- 10초마다 난이도 레벨 +0.3
- 낙하 속도: 기본 속도 + (난이도 레벨 × 40) px/s
- 생성 주기: 최소 400ms까지 점진적 감소

## 🎯 플레이 팁

1. **초반 집중**: 처음 30초가 가장 중요합니다. 안정적인 리듬을 찾으세요!
2. **보너스 아이템 우선**: 금똥과 다이아똥은 점수 상승에 큰 도움이 됩니다
3. **난이도 선택**: 처음이라면 '쉬움'으로 시작해서 감을 익히세요
4. **크리스마스 이벤트**: 12월에는 특별한 똥들을 만나보세요!
5. **랭킹 도전**: 멋진 이니셜로 기록을 남겨보세요
