# v1.0.0

2025년 12월 13일

똥 피하기 게임 첫 번째 출시

## 주요 기능

클래식 모드
- 떨어지는 똥을 피하는 기본 게임
- EASY, NORMAL, HARD, EXTREME 4가지 난이도 선택 가능
- 시간이 지날수록 점점 어려워짐

보너스 아이템
- 금똥: 특정 점수마다 등장, 획득 시 20점 추가
- 다이아똥: 특정 점수마다 등장, 획득 시 40점 추가

크리스마스 이벤트
- 12월~1월 기간 동안 크리스마스 테마 똥과 배경 음악 제공

랭킹 시스템
- 난이도별로 독립적인 리더보드
- 이니셜 3글자 입력으로 기록 등록
- 상위 10명 실시간 확인 가능

## 조작 방법

키보드: 좌우 화살표 키
터치: 화면 좌우 탭

## 팁

초반 30초가 가장 중요
금똥과 다이아똥을 우선적으로 수집
처음이라면 쉬움 난이도로 시작
