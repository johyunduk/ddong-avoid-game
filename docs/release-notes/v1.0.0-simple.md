## 새로운 기능

### 게임 모드
- **클래식 모드**: 똥 피하기 (쉬움/보통/어려움)
- **아이템 모드**: 우주 배경에서 별 피하기 + 특수 아이템

### 보너스 아이템
- 💰 **금똥**: 40점마다 등장 (+20점)
- 💎 **다이아똥**: 100점마다 등장 (+40점)

### 크리스마스 이벤트
- 12월~1월 자동 활성화
- 크리스마스 테마 똥 5종
- 특별 배경 & BGM

### 랭킹
- 난이도별 리더보드
- 이니셜 입력 (3글자)
- 실시간 상위 10명

| 난이도 | 플레이어 속도 | 똥 속도 | 생성 주기 |
|--------|--------------|---------|----------|
| 쉬움   | 350 px/s     | 180 px/s | 1200ms  |
| 보통   | 300 px/s     | 200 px/s | 1000ms  |
