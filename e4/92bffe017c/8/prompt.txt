**문제**:

```typescript
private historyIndex = 0;

this.posHistoryBuffer[this.historyIndex] = { x: api.player.x, y: api.player.y };
this.historyIndex = (this.historyIndex + 1) % this.TRAIL_FRAMES;

// shift 대신
const target = this.posHistoryBuffer[this.historyIndex];
```
