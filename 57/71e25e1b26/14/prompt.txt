4. **Ghost click — second attempt (onDown sets readyForInput)**: Same frame issue: game object `pointerdown` fires → calls `showCharSelectOverlay()` → registers scene-level `onDown` → same frame's scene-level `pointerdown` fires → `readyForInput = true` immediately.
