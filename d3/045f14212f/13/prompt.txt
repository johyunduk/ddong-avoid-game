2. Key Technical Concepts:
   - **Phaser 3 WebGL draw calls**: Each `Graphics` object in Phaser requires a separate WebGL draw call per frame. Batching many objects into a single `Graphics` (clear+redraw each frame) dramatically reduces GPU overhead.
   - **Object pooling**: Game already uses `prewarm` pattern for poop groups; new objects should follow same pattern.
   - **O(1) cached fever trigger**: `checkFeverTime` was O(k) per-call while-loop; replaced with cached `nextFeverScore`/`feverScoreK`.
   - **Single Graphics pattern**: Replace N individual Graphics objects (N draw calls/frame) with 1 persistent Graphics that `clear()`s + redraws all shapes each frame (1 draw call).
   - **glow_dot Image vs Graphics**: `glow_dot` Images with ADD blend mode are far cheaper than Graphics fillCircle for tiny particle effects; Images batch efficiently in WebGL.
   - **TypeScript strict**: `verbatimModuleSyntax=true` (type imports need `import type`), `erasableSyntaxOnly=true` (no enums; use `as const`).
   - **Rotation buffer**: For batching rotated star shapes without per-frame GC, use a static `{x,y}[]` buffer that's overwritten in-place.
