# 등급 텍스트 → 이미지 교체 계획

## Context
`public/assets/character_ranks/`에 `r.png`, `sr.png`, `ur.png` 이미지가 추가됨.
현재 R/SR/UR 등급을 텍스트로 표시하는 곳 전체를 이미지로 교체.
`등급외`는 이미지 없음 → null 처리(이미지 미표시).

---

## 1. 공통 헬퍼 추가 — `src/utils/character.ts`

```typescript
/** 등급 이미지 텍스처 키 반환. 등급외 → null */
export function getGradeImgKey(grade: string): string | null {
  if (grade === '등급외') return null;
  return `grade_${grade.toLowerCase()}`; // grade_r, grade_sr, grade_ur
}
```

---

## 2. 씬별 preload 추가

각 씬의 `preload()` 메서드에 추가:
```typescript

this.load.image('grade_sr', 'assets/character_ranks/sr.png');
this.load.image('grade_ur', 'assets/character_ranks/ur.png');
```
