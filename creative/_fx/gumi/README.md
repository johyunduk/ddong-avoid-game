# 구미 이펙트 텍스처

`public/assets/fx/particles/` 의 `tail.png` · `foxfire.png`.

## 꼬리는 그린다

```bash
C:\ComfyUI\.venv\Scripts\python.exe scripts/fx-particle.py \
  --plume --out-file public/assets/fx/particles/tail.png
```

ComfyUI 에 "구미호 꼬리 하나"를 시켰지만 **전부 여우 전체를 그렸다.** `tail` 이라는
단어가 동물을 부른다. 생성물에서 꼬리만 잘라내는 것도 해 봤지만 축을 맞추기 어려웠다.

무엇보다 이 꼬리는 **9개가 각각 다른 색으로 칠해지는 70px 물체**다. 사진 같은 털 질감을
9색으로 착색하면 탁해지고, 그 크기에서는 어차피 실루엣만 남는다.
`--plume` 로 굽는다 — 밑동 가늘고 중간이 가장 두껍고 끝이 뾰족한 깃, 결 몇 가닥.

원본이 발광 점 14개를 이어 만들던 실루엣과 같다. 다만 **9개면 스프라이트 126장을
매 프레임 재배치**하던 것이 이제 9장이다.

## 여우불은 건드리지 않았다

생성한 불꽃 텍스처로 바꿔 봤지만 **가시성이 나빠져 되돌렸다.**
여우불은 가산(ADD) 블렌드로 밝은 하늘 위에 올라간다 — 원본의 `glow_dot`(부드러운
방사 점)은 중심이 흰색으로 포화되고 가장자리에 색 후광이 남아 그 조건에서 잘 읽힌다.
결이 있는 불꽃 텍스처는 같은 조건에서 그냥 **흰 얼룩**이 된다.

## 상시 가산 이펙트는 블룸 레이어에 올리지 않는다 (YOU MUST)

꼬리를 `fxSprite` 로 옮기면서 `blend: 'add'` 로 만들었더니 두 가지가 한꺼번에 터졌다.

1. **렌더 순서 붕괴** — 블룸 레이어는 depth 가 122 로 고정이라, 올라간 오브젝트는
   자기 depth(꼬리는 3, 캐릭터 뒤)를 잃고 캐릭터 앞으로 튀어나온다
2. **영구 블룸** — 하나라도 살아 있으면 전체 화면 블룸 패스가 계속 돈다.
   꼬리는 9개가 게임 내내 살아 있으므로 사실상 상시 부하가 된다

`fxSprite` 의 `bloom` 은 이제 **기본 false** 이고, 짧게 번쩍이는 것만 켠다.
누수 계측 [13]·[14] 가 이 조합을 지킨다.
