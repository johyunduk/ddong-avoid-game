```bash
for f in public/assets/players/*.webp; do
  convert "$f" \
    -resize 208x312 \
    -gravity center \
    -background none \
    -extent 208x312 \
    "$f"
done
```
- `-resize 208x312`: 비율 유지하며 208×312 안에 맞춤 (강제 왜곡 없음)

- ImageMagick이 메모리에 전체 로드 후 쓰기 → 동일 파일 덮어쓰기 안전
